# CS-305
Artemis Financial Security Project

For this portfolio artifact, I selected my Artemis Financial Vulnerability Assessment Report. In this project, I analyzed a financial services company’s software application to identify security vulnerabilities and recommend mitigation strategies. The goal of the assessment was to evaluate the existing codebase and improve the security posture of the application through secure coding practices and vulnerability analysis.

Project Summary

Artemis Financial is a financial services company that processes sensitive client information such as account data, social security numbers, and other financial records. Because the company manages confidential information and financial transactions, secure communication and data protection are critical. The company asked me to review its software application to identify vulnerabilities and recommend improvements that would help protect sensitive data and reduce the risk of cyberattacks. The main issues addressed included weak input validation, missing encryption mechanisms, outdated dependencies, and insecure data handling practices. 

CS 305 Project One Final (1)

Identifying Security Vulnerabilities

One area I believe I did well was carefully reviewing the application to identify potential vulnerabilities and areas where security controls were missing. Through manual code review and automated dependency analysis, I identified several weaknesses such as missing input validation, insecure API interactions, and outdated libraries with known vulnerabilities. Coding securely is important because it helps prevent attacks such as injection attacks, data leaks, and unauthorized access. Strong software security also protects a company’s reputation, prevents financial loss, and ensures that customer data remains protected.

Challenges and Learning Experience

One of the more challenging parts of the vulnerability assessment process was understanding how different vulnerabilities could impact the system and how they might be exploited in a real-world scenario. However, this process was also very helpful because it improved my understanding of how secure software should be designed and how small weaknesses in code or dependencies can create significant security risks.

Improving Security Layers

To strengthen the application’s security, I recommended implementing stronger encryption protocols, improving input validation, and updating outdated software dependencies. I also emphasized the importance of secure API design and better error handling to prevent sensitive information from being exposed. In the future, I would continue using automated tools such as OWASP Dependency-Check and vulnerability scanning tools, along with manual code reviews, to identify vulnerabilities and determine appropriate mitigation strategies.

Ensuring Secure and Functional Code

After making security improvements and refactoring the code, I ensured the application remained functional by reviewing the updated code and re-running vulnerability scans. Running dependency-check reports helped confirm that previously identified vulnerabilities were addressed and that no new issues were introduced during refactoring. This process helps maintain both functionality and security within the application.

Tools and Practices Used

Several tools and practices used in this project will be valuable for future development work. These include secure coding principles, static analysis tools such as OWASP Dependency-Check, proper dependency management with Maven, and implementing encryption techniques like SHA-256 hashing and HTTPS communication. These practices help developers proactively identify and mitigate security risks throughout the software development lifecycle.

Portfolio Value

This project demonstrates my ability to perform a vulnerability assessment, identify security risks in software applications, and recommend solutions to improve system security. For future employers, this artifact highlights my knowledge of secure coding practices, vulnerability analysis, and the use of industry tools to strengthen application security.
